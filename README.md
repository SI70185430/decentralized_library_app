# 分散型図書館アプリ

![分散型図書館](assets/readme/00_分散型図書館.png)

<br />

## サービス概要
本アプリケーションは、就労移行支援におけるアプリケーション開発訓練の一環として制作したものです。<br />
訓練で提示されたアプリケーション要件をもとに、要件定義から設計・実装までを行いました。<br />
社内の複数の場所に保管された書籍を一つの図書館として利用するための社内向けアプリとして制作しており、<br />
スマートフォン向けのUIで、書籍の検索や保管場所の確認を手軽に行えます。

<br />

## アプリへの想い
様々な場所に点在する書籍を一つの図書館として気軽に利用できるようにしたいと考えました。<br />
書籍を探したいときに、その場で必要な情報へアクセスできるようにスマートフォン向けに設計しており、<br />
書籍の検索から保管場所・利用状況の確認、貸出・予約・返却までを一元化することを目指しています。

<br />

## 今後の展望

本アプリの開発を通じて得た学びを基に、今後の改善と成長につなげるために、特に優先して取り組むべきと感じた内容を以下に整理しました。

### AI Agentを活用した開発体制・プロセスの整備

- プロジェクト固有の開発規約、設計方針、検証手順を `AGENTS.md` に整理して、AI Agentによる出力や作業手順のばらつきを抑える。
- 要件整理、実装、コードレビュー、テスト内容の確認を複数のAI Agentに役割ごとに分担していた一方で、AI Agent間の情報共有や作業指示は手動のプロンプト入力に依存していた。各AI Agentの成果物とタスクの状態を基に、次の担当AI Agentへの指示・引き継ぎを管理する仕組みを整備して、効率的かつ一貫した開発プロセスを実現する。
- AI Agentへの指示内容や修正内容・履歴を記録して、AI Agentを活用した場合でも判断の根拠を追跡できる開発を目指す。

### 保守性・コード品質・変更履歴の追跡性の向上

- 保守性を高める設計・実装のベストプラクティスを学び、処理の役割やレイヤー間の責務、入出力の契約、エラー発生時の振る舞いを整理して、実装の意図を把握しやすく、変更しやすいコードベースを構築する。
- 共通コンポーネントと `globals.css` に定義した共通スタイルを活用・拡充して、画面間で重複するUI実装を減らしながら、見た目と操作性の一貫性を高める。
- 複数の目的を1つのGit commitにまとめず、機能追加・修正・設定変更などを適切な単位で記録して、変更の目的が伝わるcommit messageを付与することで、継続的な保守と改善を行いやすくする。

### 安全なサービス利用を支えるセキュリティ設計

- セキュリティ要件に関する理解を深め、設計段階から保護すべき情報、利用者ごとの権限、想定される脅威を整理して、必要な対策を実装とテストに反映する。
- API経由の呼び出しだけを前提とせず、サービス関数が別の経路から利用される場合にも安全に利用できるように設計する。
